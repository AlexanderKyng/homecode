Launch a new agent to handle complex, multistep tasks autonomously.

When using the Task tool, you must specify a subagent_type parameter to select which agent type to use.

Required:
- subagent_type
- Detailed task description with desired output format
- State whether the agent should research, write code, or both
- Include validation/test steps when relevant

Guidelines:
- Use Read, Glob, or Grep for direct file/symbol lookups
- Run multiple agents in parallel when tasks are independent
- Agent returns one final result and a task_id
- Reuse task_id to continue the same session/context
- New agents start with fresh context unless resumed
- Agent outputs can generally be trusted

Best for:
- Large investigations
- Cross-file or project-wide analysis
- Refactoring and implementation work
- Autonomous workflows requiring many tool calls
- Tasks where a dedicated agent can work independently

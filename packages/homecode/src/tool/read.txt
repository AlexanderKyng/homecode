Read local files/directories.

- filePath must be absolute
- Returns up to 2000 lines by default
- offset = starting line (1-based)
- anchorHash = start from line with this hash (overrides offset). Use after edits shift line numbers.
- Read later sections with larger offsets
- Use grep for targeted search in large files
- Use glob if the path is unknown
- Prefer larger reads over many small chunks
- Read multiple files in parallel when possible

Output:
- Files: <line>|<hash>| <content>
- hashLines=false: <line>: <content>
- Directories: one entry per line, subdirs end with /

Notes:
- Line hashes support reliable edits
- Lines >2000 chars are truncated
- Can read images and PDFs as attachments

Errors if the path does not exist.

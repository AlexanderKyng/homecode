Persistent memory via MemPalace (local vector DB) with cross-session agent/user recall.

Tools:
search(query, wing, room, limit) — Semantic memory search. Defaults to current project (wing).
write(wing, room, content) — Store verbatim memories (decisions, learnings, context).
read(agent_name, last_n, wing) — Read agent diary/history.
status() — Memory counts, wings, and rooms overview.

Wing defaults to the current project directory; modify only for cross-project access.
If unavailable, install with: pip install mempalace

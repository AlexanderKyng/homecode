LSP code intelligence.

Operations:
- goToDefinition
- findReferences
- hover
- documentSymbol
- workspaceSymbol(query)
- goToImplementation
- prepareCallHierarchy
- incomingCalls
- outgoingCalls

Required:
- filePath
- line (1-based)
- character (1-based)

workspaceSymbol:
- query filters symbols; empty = all symbols
- filePath is only used to select/start the correct LSP server

Requires a configured LSP server for the file type; otherwise returns an error.

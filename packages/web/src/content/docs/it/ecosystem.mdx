Una raccolta di progetti della comunità costruiti su OpenQCode.

:::note
Vuoi aggiungere il tuo progetto legato a OpenQCode a questa lista? Apri una PR.
:::

Puoi anche dare un'occhiata a [awesome-openqcode](https://github.com/awesome-openqcode/awesome-openqcode) e [openqcode.cafe](https://openqcode.cafe), una comunità che aggrega ecosistema e community.

Una raccolta di progetti della comunità costruiti su HomeCode.

:::note
Vuoi aggiungere il tuo progetto legato a HomeCode a questa lista? Apri una PR.
:::

Puoi anche dare un'occhiata a [awesome-homecode](https://github.com/awesome-homecode/awesome-homecode) e [homecode.cafe](https://homecode.cafe), una comunità che aggrega ecosistema e community.

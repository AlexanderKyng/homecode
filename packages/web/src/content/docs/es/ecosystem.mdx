Una colección de proyectos comunitarios construidos en HomeCode.

:::note
¿Quieres agregar tu proyecto relacionado con HomeCode a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-homecode](https://github.com/awesome-homecode/awesome-homecode) y [homecode.cafe](https://homecode.cafe), una comunidad que agrega el ecosistema y la comunidad.

ชุดโครงการชุมชนที่สร้างขึ้นบน HomeCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ HomeCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-homecode](https://github.com/awesome-homecode/awesome-homecode) และ [homecode.cafe](https://homecode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน

---

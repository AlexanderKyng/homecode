ชุดโครงการชุมชนที่สร้างขึ้นบน OpenQCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenQCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-openqcode](https://github.com/awesome-openqcode/awesome-openqcode) และ [openqcode.cafe](https://openqcode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน

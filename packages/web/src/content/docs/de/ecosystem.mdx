Eine Sammlung von Community-Projekten, die auf HomeCode basieren.

:::note
Möchten Sie Ihr HomeCode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-homecode](https://github.com/awesome-homecode/awesome-homecode) und [homecode.cafe](https://homecode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.

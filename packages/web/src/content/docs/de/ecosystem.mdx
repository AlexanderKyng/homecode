description: Mit OpenQCode erstellte Projekte und Integrationen.
---

Eine Sammlung von Community-Projekten, die auf OpenQCode basieren.

:::note
Möchten Sie Ihr OpenQCode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openqcode](https://github.com/awesome-openqcode/awesome-openqcode) und [openqcode.cafe](https://openqcode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
